# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Promptcraft, please report it responsibly:

1. **Email**: Open a security advisory or email the maintainer directly.
2. **Details**: Provide steps to reproduce, impact assessment, and any suggested fixes.
3. **Disclosure Policy**: Please do not disclose vulnerabilities publicly until a fix is released.
